01

Normal Distribution — Manufacturing Quality Control

Factories measure parts to check whether they are close enough to the target size.

Industry problem: A factory produces metal shafts with a target diameter of 10 mm. Small variations happen during manufacturing. The quality team wants to estimate the proportion of shafts that fall inside the acceptable diameter range.

Input parameters

Mathematical formulas

Probability density: f(x) = [1 / (σ√(2π))] × exp(−(x − μ)² / (2σ²))
Interval probability: P(a ≤ X ≤ b) = Φ((b − μ)/σ) − Φ((a − μ)/σ)
Defective percentage = [P(X < LSL) + P(X > USL)] × 100%

Φ(z) is the Normal cumulative distribution function (CDF). The CDF gives the probability that a value is less than or equal to a chosen point.

02

Exponential Distribution — Cloud Request Inter-arrival Time

Cloud platforms receive requests from users and applications at different times.

Industry problem: A cloud service receives requests at an illustrative average rate of 12 requests per minute. The Exponential Distribution models the waiting time between consecutive requests when arrivals follow a constant-rate Poisson process.

Input parameters

Mathematical formulas

Density: f(t) = λe−λt, for t ≥ 0
P(T ≤ t) = 1 − e−λt
P(T > t) = e−λt
Mean = 1/λ; Variance = 1/λ²
P(T > t₂ | T > t₁) = e−λ(t₂ − t₁), for t₂ ≥ t₁

For calculations, the rate is converted from requests per minute to requests per second by dividing λ by 60. Mean is in seconds and variance is in seconds².

Memoryless property: If no request has arrived yet, the probability distribution of the additional waiting time is the same, regardless of how long you have already waited. This is a property of the exponential model.

Model assumption: This module assumes a constant-rate Poisson arrival process. Inter-arrival time is the time between incoming requests; it is not the same as server response time.
